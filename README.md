# One Word From Grandma

One-word entry for the make.fun bounty
[One Word From Grandma](https://make.fun/bounty/u-0xkianno-one-word-from-grandma-f04bed16).

The program writes exactly one word — the word my grandma would text
about AI — to `/output/entry.txt`, UTF-8, with no trailing newline.

## How to run

```sh
python3 main.py
```

This writes the single-word entry to `/output/entry.txt`.
After writing, `main.py` reads the file back and exits with an error
if it does not match the entry byte-for-byte.

## Entry

`Knowitall` — 9 characters, one word, nothing else.
